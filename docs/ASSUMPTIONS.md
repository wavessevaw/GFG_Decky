# Допущения (SSMT, функция №1)

Каждое допущение помечено статусом: **[предложено]** — ждёт подтверждения, **[принято]** — подтверждено заказчиком, **[изменено]** — пересмотрено (с причиной).

## Сигнал и измерение
- A1 [предложено] Основной тестовый сигнал — случайный розовый шум (в ТЗ — «серый шум»). Белый, «серый» (с обратной кривой равной громкости ISO 226 на 60 phon) и полосовой — опции.
- A2 [предложено] Режим референса по умолчанию — B (внутренний), задержка находится один раз на шаге 1 и замораживается на всю сессию мастера; аудиопоток не перезапускается между шагами.
- A3 [предложено] Режим B требует, чтобы вход и выход были на одном устройстве (общие часы) или в агрегатном устройстве с drift-correction.
- A4 [предложено] Частота дискретизации 48 кГц; 96 кГц — опция в настройках, размеры окон масштабируются ×2.
- A5 [предложено] Минимальная длительность одного замера — 12 с (≈ 30 усреднений для окна 65536 при перекрытии 75 %).
- A6 [предложено] Порог когерентности для маскирования — 0.6 (как в ТЗ), для «светофора» качества: ≥ 0.8 хорошо, 0.6–0.8 слабо, < 0.6 повторить (по медиане в рабочей полосе).

## Безопасность уровня
- A7 [предложено] Стартовый уровень −60 dBFS RMS, fade-in 2 с, шаг автоуровня не более 3 dB/с, цель SNR ≥ 20 dB, пользовательский потолок по умолчанию −12 dBFS RMS. Brick-wall лимитер на −1 dBFS peak.
- A8 [предложено] STOP обнуляет выход без затухания (мгновенно, в пределах одного аудиобуфера).
- A9 [предложено] Клиппинг = отсчёт с |x| ≥ −0.1 dBFS на любом измерительном входе; замер с клиппингом не принимается.

## SPL
- A10 [предложено] Lpeak = LCpeak, Lmax = LAFmax (временная константа Fast, 125 мс).

## Выравнивание
- A11 [предложено] При τ < 0 (саб приходит позже) рекомендуется задержать топы на |τ| с пояснением.
- A12 [предложено] Правило неоднозначности «< 10 %» применяется после отбора кандидатов в окрестности грубой IR-оценки и проверки в расширенной полосе (см. PLAN.md, 5.1), иначе оно срабатывает почти всегда из-за периодичности J(τ).
- A13 [предложено] Шаг округления задержки по умолчанию 0.01 мс; уровень — 0.5 dB.

## EQ
- A14 [предложено] Целевые кривые (стартовые, редактируемые):
  - «Плоская»: 0 dB.
  - «Живой звук / PA»: +3 dB полка ниже 100 Гц (низкая полка, Q 0.7), спад −1 dB/окт. от 1 кГц (≈ −4 dB на 16 кГц).
  - «Речь»: HPF-образный спад ниже 120 Гц (−6 dB/окт.), +1.5 dB в 2–4 кГц, спад −1 dB/окт. от 6 кГц.
  - «Клуб»: +6 dB полка ниже 90 Гц, спад −1.5 dB/окт. от 1 кГц.
- A15 [предложено] Лимит 8 полос PEQ — на каждую группу (саб, топы) отдельно — **ждёт ответа на вопрос Q8**.

## Платформа
- A16 [принято] macOS 13+, universal binary (arm64 + x86_64), без внешних runtime-зависимостей; XcodeGen — только build-time.
- A17 [принято] Сборка и тесты приложения — бесплатный GitHub Actions (публичный репозиторий): Linux + macOS. Ручная проверка звука и анимаций — по чек-листу на реальном Mac.
- A18 [предложено] Данные калибровок микрофонов в приложение не вшиваются — только импорт пользователем.

## Решения заказчика и производные допущения (2026-10-02)
- A19 [принято] Шаги «только саб» / «только топы»: приложение просит пользователя замьютить сателлиты (оставить сабы) и наоборот; управление процессором — вне v1.
- A20 [принято] Логотип: используются только файлы из `App/SSMT/Resources/Brand` (`BrandLogoFull`, `BrandMark`, PDF или PNG). До их появления — текстовая заглушка «SSMT», не имитирующая знак.
- A21 [принято] Палитра: оранжевый `#FF6B1A`, оранжево-красный `#FF4419`, жёлтый `#FFC21A`, чёрный. Ошибка — красный `#FF2D3D` всегда с иконкой и словом.
- A22 [предложено] Статус «хорошо» в светофоре — зелёный `#4BE08A` только на значках статуса (общепринятая семантика светофора); если нужен строго оранжево-жёлтый интерфейс — заменим на белый ✓.
- A23 [принято] Распространение — публичный `.pkg` без Developer ID (ad-hoc подпись). Следствие: при первом запуске Gatekeeper требует подтверждения в системных настройках; разрешение на микрофон может запрашиваться заново после обновления версии.
- A24 [предложено] Шрифты на этапе 1 — системные (SF моноширинный с табличными цифрами, SF condensed для заголовков). JetBrains Mono и заголовочный шрифт с кириллицей (OFL) встраиваются на этапе 5.
- A25 [предложено] «Серый» шум (обратная кривая равной громкости ISO 226) и полосовой шум в UI — этап 2; розовый, белый и периодический розовый доступны с этапа 1.
- A26 [предложено] Поиск задержки (GCC-PHAT) реализован на этапе 1, т.к. без компенсации задержки графики когерентности и фазы на ВЧ неинформативны. Полоса анализа 100 Гц–12 кГц, диапазон 0–500 мс, критерий надёжности: пик/второй пик ≥ 2 и пик/шум ≥ 12 dB.
- A27 [предложено] Мульти-окно: кроссфейд между окнами 1/3 окт. (±1/6), бины с частичными весами по перекрытию с полосой ppo; для полос уже двух бинов — линейная интерполяция.
- A28 [предложено] Живой режим — экспоненциальное усреднение с постоянной 1.5 с; захват (capture) — линейное среднее за весь замер.

## Этап 3 — выравнивание и мастер
- A29 [предложено] **Уровень саба (ТЗ 6.5).** При известной частоте раздела — как в ТЗ: медианы |H_s| и |H_m| в зоне перекрытия. При автоопределённой частоте раздела зона перекрытия центрирована на точке равенства уровней по построению, поэтому медианы совпадают всегда и метод даёт ≈0 dB. В этом случае уровень считается по полосам пропускания: топы в [2·fc, 4·fc], саб в [fc/4, fc/2]. Для обоих вариантов используются точки с γ² выше порога **каждой кривой отдельно** (без фильтра «уровни в пределах 12 dB», который смещал бы разницу к нулю).
- A30 [предложено] **Неоднозначность (ТЗ 6.4).** В узкой зоне перекрытия «инверсия при τ» и «прямая при τ ± ½ периода» отличаются по J на 2–5 %, поэтому буквальное правило «< 10 % → неоднозначно» срабатывало бы почти всегда. Кандидаты в пределах 10 % по J, которые лежат дальше ¼ периода (0.25/fc) от грубой оценки по импульсным характеристикам, считаются срывом на полпериода и отбрасываются (видны в «Эксперте»). Предупреждение выдаётся, если в окне ±¼ периода остаётся больше одного кандидата или грубой оценки нет. Проверено тестами: реальные залы → однозначно, квадратурный саб (90°) → предупреждение.
- A31 [предложено] Грубая оценка — пик огибающей полосно-ограниченной ИХ (неравномерное обратное ДПФ по точкам сетки в зоне перекрытия с окном Ханна в лог-частоте), поиск ±80 мс.
- A32 [предложено] Качество замера на шаге оценивается в полосе измеряемой группы: «только саб» — 30 Гц…1.5·fc, «только топы» — fc/1.5…16 кГц, остальные — 40 Гц…16 кГц (fc = 100 Гц, если неизвестна).
- A33 [предложено] Метрики проверки: «сложение» = медиана (20·lg|H_total| − 10·lg(|H_m|²+|H_s|²)) в зоне перекрытия (+3 dB — идеально когерентно, 0 — некогерентно); «провал» = худшее отрицательное значение. «Отлично»: провал < 3 dB и отклонение от прогноза < 2 dB СКО; «Хорошо, но…»: провал < 6 dB и отклонение < 3 dB; иначе — «Проверьте…» с наиболее вероятной причиной (полярность / задержка не введена / задержка не той группе / уровень).
- A34 [предложено] Если задержка зафиксирована, а аудиопоток перезапустился (счётчик разрывов изменился), мастер возвращается к шагу 0 и требует новую фиксацию и повтор замеров.
- A35 [предложено] Длительность одного замера в мастере — 12 с (ТЗ: 10–20 с для точек EQ; для шагов 1–5 взято то же).
