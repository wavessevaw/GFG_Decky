# Статус разработки

## Этап 1 — каркас, ядро, генератор, захват, графики, симуляция

**Сделано**
- `SSMTCore` (Swift Package, без UI): FFT (Accelerate + переносимый radix-2), Welch Gxx/Gyy/Gxy,
  H(f) и γ²(f), мульти-оконный анализ 65536/16384/4096/1024 со сшивкой, сетка 24 ppo,
  сглаживание 1/48…1/3 окт., развёртка фазы и компенсация задержки, Hilbert-огибающая и IR,
  RBJ-биквады и кроссоверы LR24/Butterworth.
- Генератор: розовый (случайный), белый, полосовой, периодический розовый; fade-in, ограничение
  скорости подъёма уровня (3 dB/с), пользовательский максимум, пиковый лимитер, мгновенный STOP.
- Lock-free SPSC ring buffer и атомики на C11 (`SSMTRealtime`).
- Измерительный движок: живой анализ (экспоненциальное усреднение) и захват (capture) с оценкой
  качества «хорошо / слабо / повторить», детектор клиппинга (захват с клиппингом не принимается),
  индикаторы входов, поиск и фиксация задержки GCC-PHAT (до 500 мс), учёт разрывов потока.
- Виртуальная система (саб + сателлиты + отражения + комнатные моды + шум микрофона) и
  симулированное аудиоустройство — приложение работает без железа.
- Core Audio: дуплексный AUHAL на одном устройстве, выбор каналов, колбэки без аллокаций,
  счётчик разрывов (сэмпл-таймы + перегрузка устройства).
- Приложение: тёмный индустриальный интерфейс (оранжевый/жёлтый/чёрный), графики АЧХ/фаза/
  когерентность с штриховкой зон низкой когерентности, настройка источника и генератора,
  STOP (Esc отовсюду), переключатель ru/en.
- CI (бесплатно): тесты ядра на Linux и macOS, universal-сборка `.app` (артефакт `SSMT-app`).

**Тесты ядра (33):** FFT против эталонного DFT; совпадение бэкендов; наклон розового шума −3 dB/окт;
H(f) против аналитики (±0.25 dB, ±3°, γ² > 0.98); непрерывность на стыках окон; γ² = S/(S+N);
точность H при умеренном SNR; задержка с точностью ±1 отсчёт до ~470 мс с шумом; отказ на
некоррелированном сигнале; лимитер, fade, ограничение скорости, STOP; ring buffer (в т.ч.
2 потока × 2 млн отсчётов); сквозной захват через движок; отклонение захвата с клиппингом.

**Не сделано / ограничения этапа 1**
- Не проверено на реальном звуке — нужен ваш ручной прогон (чек-лист ниже).
- Агрегатные устройства (вход и выход на разных картах) — этап 2.
- Шрифты — системные, логотип — заглушка до появления файлов.
- Снапшот-тесты UI — этап 5 (вместе с финальным дизайном).

## Этап 2 — задержка, калибровка микрофона, SPL, безопасность уровня

**Сделано**
- Поиск задержки GCC-PHAT (0–500 мс, субсэмпловая точность, оценка надёжности) и фиксация на всю сессию; показ в мс и метрах с учётом температуры.
- Импорт калибровки микрофона: текстовые файлы «частота — dB [— фаза]», заголовок чувствительности
  (`Sens Factor`, `Sensitivity`), серийный номер, CSV/табуляция/европейские десятичные; только магнитуда,
  логарифмическая интерполяция; библиотека профилей пользователя; пометка «Микрофон не откалиброван».
- SPL: взвешивания A/C/Z (IEC 61672, проверено против аналитики), LAeq, LCeq, LCpeak, LAFmax;
  калибровка значением dBFS@94 dB, по чувствительности (мВ/Па) или калибратором 94/114 dB.
- Безопасность: замер шума помещения, автоуровень до SNR ≥ 20 dB с ограничением скорости,
  остановка на пользовательском максимуме, отступ −6 dB при клиппинге; лимитер, fade, STOP.
- Разные карты для входа и выхода: частное агрегатное устройство с коррекцией дрейфа.

**Тесты ядра: 43** (добавлены: парсинг калибровок, интерполяция, A/C против IEC, калибровка
94 dB → LAeq/LCeq/Lpeak/Lmax, чувствительность мВ/Па, автоуровень: цель / максимум / клиппинг).

**Не сделано / на проверку**
- Агрегатное устройство и реальная латентность — только на живом Mac (чек-лист п. 8).
- «Серый» и полосовой шум в UI — перенесено на этап 3 вместе с мастером.

## Ручной чек-лист (на Mac)
1. Скачать артефакт `SSMT-app` из последнего прогона CI → распаковать → открыть
   (первый запуск: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»).
2. Источник «Симуляция» → «Запустить аудио» → «Включить шум» → через ~2 с появляются графики.
3. «Найти задержку» (⌘D) → ≈ 38.4 мс (10.7 мс латентности виртуальной карты + 9.5 м до сателлитов); когерентность на ВЧ высокая, кроме зон гребёнки от отражения.
4. Выключить «Сабвуферы» / «Сателлиты» — АЧХ меняется соответственно.
5. Esc при любом фокусе → шум мгновенно глохнет.
6. Реальная карта: выбрать устройство, вход микрофона, выход → разрешить микрофон → те же шаги
   на минимальном уровне. Проверить индикатор CLIP, изменив усиление преампа.
7. Свернуть окно на 1 минуту и развернуть — усреднение не сброшено.
8. «Разные устройства для входа и выхода» → выбрать USB-микрофон и другую карту → запустить → «Найти задержку» → когерентность стабильна несколько минут (нет дрейфа).
9. «Автоуровень» в тихом помещении: сначала 5 с тишины, затем плавный подъём, остановка с сообщением о SNR.
10. Импортировать файл калибровки своего микрофона → кривая АЧХ смещается на его поправку.
11. Калибратор 94 dB на микрофон → «Считать калибратор» → LAeq ≈ 94 dB.
